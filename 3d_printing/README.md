# 3D-printed enclosure

## Model file

The original model is named `Overkill.3mf`. It belongs in this directory alongside the preview image linked from the project README.

> **Model upload pending:** the original binary 3MF is not yet committed to this repository. The image preview is not a printable substitute. Download the original model from the project maintainer's shared artifact and upload it here as `Overkill.3mf`.

## Material

**Print the enclosure in PETG.** Start with the PETG profile recommended by your filament manufacturer for your printer and nozzle. The project does not yet publish validated nozzle/bed temperatures, fan speed, layer height, infill, supports or orientation, so do not treat generic values as tested settings.

## Before full printing

1. Open the 3MF in your slicer and inspect all model objects and any colour/material assignments.
2. Check the preview for walls, openings, supports and bed placement.
3. Print a small fit-check first when practical.
4. Test fit the ESP carrier, connectors and cable exit points. Make sure the IR transmitter and receiver have the intended optical openings.
5. Check screw lengths and board clearance; don't allow metal hardware to contact exposed circuit pads.
6. Record validated slicer settings and any model changes after a real assembly.

The labeled model-derived exterior view is available in [hardware/OverKill-3MF-Labeled-Product.svg](../hardware/OverKill-3MF-Labeled-Product.svg). It shows enclosure features only; internal electronics are not part of the 3MF render.
